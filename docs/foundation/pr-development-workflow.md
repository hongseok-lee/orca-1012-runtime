# PR and development workflow

Follow the root [PR·개발환경 policy](../plans/orca-1012-pr-development-workflow.md)
and [public AGENTS rules](../../AGENTS.md). The policy copy preserves the latest
source-baseline decision and requirements, with only authorized private-information
generalization. Source and public-copy hashes are in
[the export manifest](../../provenance/public-doc-export.json).

The full assigned foundation section must appear in each PR body. Missing actual
runtime or screenshot evidence keeps the foundation PR draft. The root reviews the
latest head SHA and alone decides acceptance and merge; no independent self-approval
is claimed. Feature work waits for the user's explicit final start instruction.
