# O-02 — 1012 정본·참조 문서 로컬 보존 완료 기록

상태: 기존 실행 완료 · 구분: 기획 기준 자료의 보존 명세.
근거: REFERENCE-MANIFEST (비공개 운영 기록), SHA256SUMS (비공개 운영 기록). [공통 계약](COMMON.md)을 적용한다.

## 목적과 완료 범위

클러스터 삭제 후에도 1012 계획과 haagent/NFS 참고 자료를 읽을 수 있도록 원본 구조와 내용을 로컬 저장소에 보존했다. 보존 자료와 현재 실행 환경의 사실을 구분한다.

## 보존 계약

1. 정본은 [orca-durable-session-snapshot-rpc-spec-20261010.md](../../reference/haagent-20261012/plans/orca-durable-session-snapshot-rpc-spec-20261010.md)의 2026-10-12 개정 본문이다.
2. 원본 위치는 `<historical-nfs-source>/docs/plans/orca-durable-session-snapshot-rpc-spec-20261010.md`였다. 삭제된 클러스터의 mount를 현재 접근 가능한 경로로 가정하지 않는다.
3. private 원본 문서 33개, 총 1,547,012 bytes를 `docs/reference/haagent-20261012/`에 상대 구조대로 보존했고 private 원본은 byte-identical로 보존됨을 확인했다. 공개 사본은 별도 hash로 구분한다.
4. private 원본 정본은 1,448행·191,448 bytes, 원본 SHA-256 `76b52dc79f4ac5fd1274131564aba3cc1d53e1a88b0810fa031ae27ec0dfc200`이다.
5. 1011 공용 인계/연구/실험은 참고다. 1012 확정 내용을 덮어쓰거나 과거 실험 성공을 현 제품 합격으로 바꾸지 않는다.
6. 원 대화 전체·인증 자료를 repo 참조 디렉터리에 추가하지 않는다. 전체 NFS 보존은 O-01의 보호된 백업과 구분한다.

## 완료 증거와 유지

manifest의 복사 출처·파일 목록과 SHA256SUMS가 byte 동일성의 근거다. 정본/원 보고서는 후속 계획 편집으로 덮어쓰지 않는다. 이번 개별 명세는 새 파생 문서이며 private 원본 정본은 그대로 보존한다.

## 후속 연결

모든 개별 명세는 위 로컬 정본의 절 번호를 참조한다. 현재 소스·플랫폼 지원은 [G-01](G-01.md)~[G-05](G-05.md)에서 따로 확인한다.
