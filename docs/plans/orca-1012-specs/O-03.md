# O-03 — 역할 분리·동결 orphan 템플릿 운영 기록

상태: 운영 규칙 기록 완료 · 구분: 모든 위임에 계속 적용할 계약.
근거: [AGENTS.md](../../../AGENTS.md), [운영 지시](../../../AGENTS.md), [템플릿 기록](../../../AGENTS.md). [공통 계약](COMMON.md)을 적용한다.

## 역할 계약

계획 해석·작업목록·분해·우선순위·의존성·수용기준·최종 판정은 root 오케스트레이션 전담이다. 실행 worker는 `gpt-6.1-sol` / reasoning `high`로 구체적 코드 작성·실행·검증·증거 기록을 수행한다. 사용자가 명시한 독립 리뷰 의견은 자문이며 채택/계획 변경은 root가 결정한다.

## 동결 원본

| 항목 | 보존 값 |
|---|---|
| orphan template | `<frozen-template-id>` |
| 고정 완료 cutoff | `<frozen-template-cutoff>` |
| 모델/effort | `gpt-6.1-sol` / `high` |
| 지속 메모리 | `비공개 운영 메모리` |
| 보존 snapshot | `비공개 template registry로 지정` |

## 반드시 유지할 조건

1. orphan 원본을 실제 작업에 사용하지 않는다. resume·turn/start·queue·후속 지시·코드/시험·compact·rollback·이름/pin/설정/이력 변경을 금지한다.
2. 오직 고정 완료 cutoff에서 별도 worker를 fork하는 source로 참조한다. 검증은 읽기/hash만 가능하며 KV warming도 예외가 아니다.
3. 본 root 세션은 계속 진행하는 오케스트레이터다. 동결 원본을 root로 바꾸지 않는다.
4. 신규 worker는 동일 저장 prefix에서 시작한다. 유사 작업 재사용은 root 판단으로 worker에만 적용하고 실행 결과를 template에 병합하지 않는다.
5. template·history_base 원본 세션·이력 DB·보존 snapshot을 자동 archive/delete/GC하지 않는다.
6. 동일 저장 prefix 확인과 서버 KV cache hit 보장은 다르다. 영구 KV 유지나 서로 다른 모델 사이 KV 공유를 약속하지 않는다.

## 완료·유지 증거

운영 지시·AGENTS·템플릿 기록·지속 메모리에 규칙을 기록했다. 과거 검증은 해당 기록과 리뷰 실행 기록에 남아 있다. 이 파일 작성은 template를 재개하거나 변경하는 작업이 아니며 새 작업별 지시는 별도 worker suffix에만 제공한다.
