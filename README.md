# Orca 1012 Runtime

Development foundation for reviewed Orca runtime changes, based on the public
[stablyai/orca](https://github.com/stablyai/orca) source.

The initial main branch contains repository bootstrap and upstream provenance.
Source import and development tooling are submitted through pull requests.
Foundation preparation does not implement or qualify the planned product features.

See [upstream provenance](UPSTREAM.md) and the preserved [MIT license](LICENSE).
